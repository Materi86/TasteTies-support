# TasteTies support

Public static support and privacy website at https://materi86.github.io/TasteTies-support/.

The Swedish and English policies are rendered from the app's authoritative `src/locales/{sv,en}/legal.json` files on `codex/tasteties-redesign`. Update app and website together when data handling changes.

GitHub Pages publishes the root of main. Only reviewed static files belong here. Contact details were supplied by the owner on 7 November 2026.

Preview with `python3 -m http.server 4173`.
